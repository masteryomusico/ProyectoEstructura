Tema 05
🔗

Listas Enlazadas

Nodos conectados por referencias. Permiten inserción/eliminación eficiente sin necesidad de reubicar elementos.

class Nodo: def __init__(self, dato): self.dato = dato self.sig = None n1 = Nodo(10); n2 = Nodo(20) n1.sig = n2 # 10 → 20
Punteros
Tema 06
📚

Pilas (Stack) — LIFO

Last In, First Out. Úsala para historial de acciones, llamadas de funciones y evaluación de expresiones.

pila = [] pila.append("google.com") pila.append("youtube.com") pila.append("github.com") print(pila.pop()) # → github.com
LIFO
Tema 07
🎟️

Colas (Queue) — FIFO

First In, First Out. Perfecta para gestión de turnos, impresión de documentos y procesamiento por orden de llegada.

from collections import deque cola = deque() cola.append("Cliente 1") cola.append("Cliente 2") print(cola.popleft()) # → Cliente 1
FIFO

# Ctrl+Z → pila historial = [] historial.append("acción 1") historial.pop() # deshace # Pedidos → cola from collections import deque pedidos = deque() pedidos.append("Pedido A") pedidos.popleft()
Integración
Tema 09
🌳

Árboles Binarios de Búsqueda (BST)

Estructura jerárquica no lineal. Cada nodo tiene máx. dos hijos. Permite búsquedas en O(log n) en árboles balanceados.

def insertar(raiz, v): if raiz is None: return Nodo(v) if v < raiz.val: raiz.izq = insertar(raiz.izq, v) else: raiz.der = insertar(raiz.der, v) return raiz # 5 → 3,7 → 1,4
No lineal
